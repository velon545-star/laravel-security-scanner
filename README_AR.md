# فاحص Laravel الأمني – دليل المطور العربي

## ما هو؟
سكربت Python يفحص مشروع Laravel تلقائياً ويكشف عن 9 ثغرات أمنية شائعة:
- APP_KEY مكشوف
- APP_DEBUG=true في الإنتاج
- SQL Injection
- XSS
- CSRF معطل
- رفع ملفات غير آمن
- تجزئة كلمة مرور ضعيفة
- Mass Assignment
- Open Redirect
- كوكيز جلسة غير محمية

## كيف تستخدمه؟

### المتطلبات
- Python 3.8+
- لا يحتاج أي مكتبات خارجية

### الاستخدام
```bash
python laravel_security_scanner.py /path/to/your/laravel/project
```

### المخرجات
- تقرير مفصل في الطرفية (Terminal)
- ملف `security_scan_report.json` في مجلد المشروع
